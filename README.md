# mdiaz.dev

Personal portfolio for Miguel Diaz — frontend-focused full-stack engineer.

Built with React 19, TypeScript, Tailwind CSS 4, and Vite. Deployed on Netlify.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # outputs to dist/
```

Content lives in `src/data.ts`; the page is `src/App.tsx`.
